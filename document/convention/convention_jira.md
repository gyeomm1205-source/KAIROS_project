# Jira Convention

## 1. 구조

- **Epic–Story** 체계만 사용 (하위 작업은 생성하지 않음)
- 모든 Story는 반드시 Epic에 연결하며, 각 담당자가 직접 생성

---

## 2. Epic 기준

- 기능 단위
- 며칠 이상 지속되는 작업 묶음일 때만 생성
- 생성 전 간단 공유

---

## 3. Story 작성

### 제목

```
[파트] 작업 내용
```

### Description

```
목적: 한 줄 요약

작업 내용: 상세 To-do 리스트

완료 기준: 기획 명세 일치, 테스트 통과, 코드 리뷰 승인
```

완료 기준 충족 시 Done 이동

---

## 4. Story Point (시간 기준)

- 1 = 1시간 이내 / 2 = 2~3시간 / 3 = 반나절 / 5 = 하루/ 8 = 이틀/ 13 = 3일
- 13점 이상의 작업은 반드시 3~5점 단위로 분할하여 생성 (21점 이상 생성 불가)

---

## 5. 예상 외 작업

- 스프린트 중 돌발 작업 발생 시 즉시 생성
- **`unplanned` 라벨을 반드시 부여**하여 계획된 작업과 구분
- 완료 후 실제 시간 기준으로 포인트 사후 지정

---

## 6. 스프린트 종료

- 미완료는 다음 스프린트로 이동
- 이동 시 한 줄 사유 작성 (예: [기획 수정] 상세 기획 변경으로 인한 재작업)

예:

- API 변경
- 우선순위 변경
- 일정 초과
- 기획 수정
