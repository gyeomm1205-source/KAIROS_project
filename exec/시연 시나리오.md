# Kairos 서비스 시연 시나리오

## 📋 시연 준비 사항

* **Google 캘린더** 세팅
* **Kairos 계정 A (신규 가입자 시연용):** GitHub, Velog 연동 및 설문 완료 상태 (온보딩부터 보여주도록 세팅)
* **Kairos 계정 B (기존 가입자 시연용):** 추천 페이지 진입 가능 상태

---

## 💻 시연 1. 기존 가입자

*히스토리 페이지를 먼저 띄운 후 진행합니다.*

### 1. 추천 페이지 (`/recommend`)
* 현재 커리큘럼 목록 확인

### 2. 커리큘럼 추천받기 (2가지 커리큘럼 비교)
* **커리큘럼 A:** 약점 보완형 (부족한 기술 중심)
* **커리큘럼 B:** 강점 살리기형 (잘하는 기술 심화)
> **🎤 멘트:** "같은 데이터에서 다른 방향의 추천이 가능합니다."

### 3. 히스토리 페이지 (`/history`)
* '기술 스택 제외' 버튼 클릭 후 '파이썬' 제외 처리
* 제외 완료 후 다시 추천 페이지의 '커리큘럼 추천받기'로 이동하여 추천 결과가 변경된 모습 시연
> **🎤 멘트:** "어떤 활동을 분석에 포함할지 사용자가 직접 통제합니다. 제외한 활동은 다음 추천에 반영되지 않습니다."

---

## 💻 시연 2. 신규 가입자

### 1. AI 분석 대기
* 실시간 진행 상태 화면 시연

### 2. 분석 결과 확인
* 기술 숙련도 / 추천 포지션 / 요약 정보 확인
* '결과가 맞습니다' 버튼 클릭

### 3. 커리큘럼 추천
* '캘린더에 추가' 버튼 클릭

### 4. 캘린더 반영 확인
* Kairos 서비스 내 캘린더에 일정이 반영된 모습 시연

### 5. 외부 캘린더 연동 확인
* Google Calendar 앱으로 이동
* 새로고침을 눌러 Kairos 일정이 실제 캘린더에 정상 반영되었는지 확인
